# 2.1 — Prose settings module

## Goal
Implement a small dependency-free `novelist.settings` module that applies the configured prose preset to an explicitly supplied valid buffer using buffer-local options only, with focused unit coverage for default behavior, opt-outs, configurability, and non-mutation guarantees.

- [x] Define local prose defaults: `enabled=true`, `filetypes={ 'markdown', 'text' }`, `spell=true`, `spelllang={ 'en_us' }`, `wrap=true`, `linebreak=true`, `breakindent=true`, and `textwidth=0`.
